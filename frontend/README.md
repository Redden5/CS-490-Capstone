# React + Vite

## Requirements

Before running the frontend, install:

- Git
- Node.js LTS 
    - macOS → .pkg
    - Windows → .msi

Check installation:

node -v
npm -v


## Setup

From the project root, go to the frontend folder:

cd frontend


Install dependencies:

npm install


Start the frontend:

npm run dev


Then open the local address shown in the terminal, usually:

http://localhost:5173
